# SnappFood NLP Sentiment Analysis

A Python-based NLP project that analyzes customer feedback for SnappFood and classifies opinions as positive or negative.

## Features
- Text preprocessing and feature extraction using `CountVectorizer`.
- Sentiment classification using `Multinomial Naive Bayes`.
- Model evaluation using accuracy score.
- A modern Tkinter graphical interface for submitting customer feedback.
- Automatic responses based on sentiment predictions.

## Technologies Used
- Python
- Pandas
- Scikit-learn
- Tkinter
- NLP (Natural Language Processing)

## How to Run
1. Clone this repository:
   ```bash
   git clone https://github.com/YOUR-USERNAME/SnappFood-NLP.git
   ```
2. Install the required libraries:
   ```bash
   pip install pandas scikit-learn numpy
   ```
3. Open `SnappFood_NLP.ipynb` in Jupyter Notebook.
4. Run the NLP model cells first, followed by the Tkinter interface cell.
